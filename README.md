# БХ — сайт цеху обладнання для переробки

Сайт підрозділу БХ: продаж і оренда обладнання, вироби з кришечок і вторсировини, послуги ЧПУ, партнерство, вакансії. Усі заявки збираються в адмінці й (за бажанням) миттєво приходять у Telegram.

Три мови інтерфейсу (UA / RU / EN), світла й темна тема, повна мобільна версія, сторінки готові для Google.

## Що є на сайті

| Сторінка | Що там |
|---|---|
| `/` | Головна: анімована схема в hero, головна ідея, анімована лінія «кришечки → дробарка → екструдер → брус → лавка», «Наша ідея», п’ять напрямів (обладнання, вироби, ЧПУ, під задачу, партнерство), власне виробництво, як ми працюємо, форма заявки, 4 напрями, рішення під ключ, хіти каталогу, калькулятор кришечок, як ми працюємо, партнерство, FAQ |
| `/equipment` | Каталог обладнання: категорії, пошук, сортування. Кнопка «До заявки» на кожній картці |
| `/equipment/<назва>` | Сторінка-лендинг позиції: галерея, ціна, наявність, оренда; далі — головна думка, «Як це працює» (кроки), «Для кого», «Що можна виготовляти», у яких рішеннях працює, характеристики й що входить, питання. Закріплене підменю розділів |
| `/caps` | Вироби з кришечок: калькулятор (скільки лавок/урн/брусу з ваших кришечок), процес, для шкіл/громад/компаній, форми «Замовити вироби» і «Здати кришечки» |
| `/products` | Усі вироби з вторсировини (кришечки, скло, метал, плитка) |
| `/services` | ЧПУ (плазма, фрезер, лазер), 3D-друк, обладнання під задачу, вироби з вашої сировини + форма з кресленнями |
| `/partners` | 6 форматів партнерства: навчити / навчитися / дилерство / постачання сировини / спільне виробництво / команда |
| `/careers` | Вакансії й стажування, відгук із резюме, «надіслати резюме» без вакансії |
| `/about`, `/contacts` | Про цех, принципи, контакти, загальна форма з вибором теми |
| `/request` | «Заявка» — кошик: кілька позицій з кількістю й форматом (купівля / оренда / під параметри) → одна комерційна пропозиція |
| `/admin` | Адмінка |

**Каталог** перенесено з маркетплейсу Gobsek (Prom): обладнання, вироби й послуги ЧПУ. Пелетна лінія та ПП «Карпати» — окреме підприємство, на сайт БХ не входять. У кожної позиції є **походження**: «власне виробництво БХ», «збираємо під замовлення» або «постачаємо» — каталог обладнання показує їх окремими блоками, змінюється в адмінці.

## Адмінка (`/admin`)

- **Огляд** — нові заявки, графік за 30 днів, типи заявок, найпопулярніші сторінки.
- **Заявки** — фільтри за статусом (Нова → В роботі → КП надіслано → Виконано / Скасовано) і типом, пошук, картка заявки з кнопками «зателефонувати / Telegram / Viber / email», файли (креслення, резюме), нотатка менеджера, історія статусів, вивантаження в Excel (CSV).
- **Каталог** — додати / змінити / копіювати / сховати / видалити обладнання, вироби, послуги. Розповідь для сторінки товару (слоган, кроки, аудиторії, що виготовляти, комплектація, питання) — у тій самій картці. Фото (до 12, стискаються автоматично, порядок і обкладинка), ціна (фіксована / «від» / за запитом), наявність, термін, оренда, ключові цифри, таблиця характеристик, переклади RU/EN, «хіт» на головній.
- **Вакансії** — додати / змінити / сховати.
- **Налаштування** — телефон, Telegram, Viber, email, адреса, графік, мапа, юр. назва, посилання на маркетплейс, умови прийому кришечок, пароль.

> Нова категорія: допишіть рядок у `server/catalog.js` (`CATEGORIES`) і перезапустіть сайт.

## Запуск локально

Потрібен лише **Node.js 22.13+**, жодних залежностей.

```bash
ADMIN_PASSWORD=ваш-пароль npm start
```

Сайт: http://localhost:3000, адмінка: http://localhost:3000/admin. Без `ADMIN_PASSWORD` пароль згенерується при першому запуску й з’явиться в консолі.

Тести: `npm test`. Почати з чистої бази: `npm run reset`.

## Публікація на Render.com

1. https://dashboard.render.com → **New → Blueprint** → репозиторій **bh** → Connect.
2. Ввести `ADMIN_PASSWORD` (і, за бажанням, Telegram-змінні) → **Apply**. Через 2–3 хвилини сайт доступний за адресою `https://bh-xxxx.onrender.com`.
3. Зайти в `/admin` → **Налаштування** → заповнити телефон, Telegram, адресу.
4. Свій домен: Render → bh → Settings → Custom Domains; потім у Environment `PUBLIC_URL=https://ваш-домен`.
5. Google: Search Console → «Префікс URL» → спосіб «HTML-тег» → значення `content` у змінну `GOOGLE_SITE_VERIFICATION` → «Підтвердити» → «Файли Sitemap» → `sitemap.xml`.

Тариф Starter + диск (~7 $/міс) — база, фото й файли заявок зберігаються в `/var/data`.

## Заявки в Telegram

1. У Telegram напишіть **@BotFather** → `/newbot` → отримайте токен.
2. Напишіть своєму боту будь-що (або додайте його в робочу групу).
3. Відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там буде `"chat":{"id": …}`.
4. На Render → Environment: `TELEGRAM_BOT_TOKEN` = токен, `TELEGRAM_CHAT_ID` = id (кілька — через кому) → Save.

Кожна нова заявка прийде повідомленням з контактами, позиціями й посиланням на неї в адмінці. Копію на пошту можна ввімкнути через `RESEND_API_KEY` + `NOTIFY_EMAIL`.

## Перед запуском перевірте

- **Контакти** — в адмінці, «Налаштування» (зараз порожні: на сайті показується лише форма).
- **Вакансії** — це приклади (зварювальник, оператор ЧПУ, інженер-конструктор, стажування): відредагуйте або сховайте.
- **Вироби з кришечок** — ціни «за запитом», фото поки що ілюстрації; додайте реальні фото в адмінці. Маса пластику на виріб (для лічильника кришечок) — орієнтовна, змінюється в картці.
- **Терміни виготовлення** в картках — орієнтовні, звірте з цехом.
- Фото каталогу при першому запуску завантажуються з Prom на диск сайту; якщо Prom недоступний — показуються з Prom напряму.

## Структура

```
server/index.js     HTTP-сервер, API, адмін-доступ, статика
server/seo.js       сторінки для Google: title, опис, Open Graph, schema.org, sitemap
server/catalog.js   розділи, категорії, типи й статуси заявок
server/db.js        база SQLite (вбудована в Node), налаштування
server/notify.js    сповіщення в Telegram / email
server/seed.js      стартове наповнення, завантаження фото з Prom
seed/items.js       стартовий каталог (обладнання, вироби, послуги)
seed/extra.js       розповіді для сторінок товарів
seed/vacancies.js   стартові вакансії
public/css/brand.css     фірмовий стиль БХ (чорний, білий, помаранчевий; Oswald + Onest)
public/             сайт: index.html, css/, js/app.js, js/i18n.js (тексти 3 мовами), js/admin.js
test/               автотести (npm test)
```
